# MathGen Landing Page

Многостраничный лендинг для платформы генерации уникальных вариантов заданий по математике.

## Тема проекта
Платформа для онлайн-обучения математике с автоматизированной генерацией уникальных вариантов заданий для преподавателей

## Использованный фреймворк
[Bulma CSS](https://bulma.io) v1.0.4

## Структура проекта
- `index.html` — главная страница (лендинг)
- `contacts.html` — контакты и отзывы с формой обратной связи
- `faq.html` — FAQ с интерактивным аккордеоном
- `404.html` — кастомная страница ошибки 404

## Демо
https://ваш-логин.github.io/mathgen-landing

## Особенности реализации
- Единый хедер и футер на всех страницах
- Активные состояния навигации
- Адаптивная верстка (мобильные устройства)
- Минималистичный дизайн без визуального шума
- Форма обратной связи с валидацией
- Аккордеон на чистом CSS/JS (без сторонних библиотек)
- Креативная страница 404 с математической тематикой
